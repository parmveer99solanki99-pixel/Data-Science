🚀 Getting Started

 Step 1: Clone the Repository

```bash
git clone https://github.com/parmveer99solanki99-pixel/Data-Science.git
```

 Step 2: Open the Repository

```bash
cd Data-Science
```

 Step 3: Install Required Libraries

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

 Step 4: Run Python Files

```bash
python 1day.py
```

You can replace `1day.py` with any Python file you want to practice.
